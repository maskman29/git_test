# IR Scope

企業の決算公告・IR資料から主要指標を登録し、最大4社を横並びで比較できるブラウザアプリです。

自己資本比率、流動比率、流動資産比率、負債比率、現金比率、固定比率などの財務安定性指標に加え、前年値や損益分岐点を登録すると成長率と安全余裕率も確認できます。

初期データには、株式会社ダイナム「第59期 2026年3月期 決算公告」から抽出した数値を収録しています。追加した企業データはブラウザの `localStorage` にだけ保存され、外部には送信されません。

## 起動

```bash
npm start
```

ブラウザで `http://localhost:4173` を開いてください。

## テスト

```bash
npm test
```

外部パッケージへの依存はありません。Node.js 18以降を推奨します。
